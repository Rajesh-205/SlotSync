# 🚀 SlotSync

> A modern AI-powered Interview Slot Booking Platform built using the MERN Stack.

SlotSync is a full-stack web application that streamlines interview scheduling by allowing candidates to book available interview slots with ease. It features secure authentication, real-time slot availability, booking management, and an AI-powered chatbot for user assistance.

---

## ✨ Features

- 🔐 Secure User Authentication (JWT)
- 📅 Interview Slot Booking
- ⏰ Real-time Slot Availability
- 📋 User Dashboard for Booking Management
- ❌ Booking Cancellation
- 🤖 AI Chat Assistant (Powered by Ollama + Llama 3.2)
- 📱 Responsive & Clean User Interface
- ⚡ Fast REST APIs using Express.js

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Rajesh-205/SlotSync.git
```

### 2. Install Dependencies

Backend

```bash
cd backend
npm install
```

Frontend

```bash
cd frontend
npm install
```

---

## ▶️ Run the Application

Backend

```bash
npm run dev
```

Frontend

```bash
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside the backend directory.

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

---

## 🤖 AI Chatbot

SlotSync includes a local AI chatbot powered by **Ollama** and **Llama 3.2**.

Before running the chatbot, ensure Ollama is installed and the model is available.

```bash
ollama run llama3.2
```
